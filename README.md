# ⚖️ BMI Calculator App

A simple and user-friendly **BMI (Body Mass Index) Calculator** built with Flutter and Dart. This application helps users calculate their BMI based on their height and weight and understand their BMI category.

## 📌 About the Project

## 🧮 BMI Formula

BMI is calculated using the following formula:

[\
\text{BMI} = \frac{\text{Weight (kg)}}{\text{Height (m)}^2}\
]

For example, if a person weighs 70 kg and is 1.75 m tall:

[\
\text{BMI} = \frac{70}{1.75^2} \approx 22.86\
]

## 📊 BMI Categories

For adults, commonly used BMI categories are:

| BMI Range      | Category       |
| -------------- | -------------- |
| Below 18.5     | Underweight    |
| 18.5–24.9      | Healthy weight |
| 25.0–29.9      | Overweight     |
| 30.0 and above | Obesity        |

*BMI is a screening measure, not a diagnosis. These adult categories are not intended for children and teenagers.*
